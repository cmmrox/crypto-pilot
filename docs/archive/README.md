# Archived design records

Files in this directory are historical design and review evidence. They are not
active implementation requirements.

Authentication references to authenticator apps or TOTP describe superseded
prototype/stage snapshots. The current owner authentication contract is defined by
`../plan/SMS_2FA_PLAN.md`, `../guidelines/SECURITY_GUIDELINES.md`, and
`../qa/reports/SMS-2FA-REPORT.md`: email and password, followed by a single-use SMS
OTP whenever owner-configurable 2FA is enabled.
